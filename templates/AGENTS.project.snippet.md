## Project context order

Use this order before opening larger files:

1. `AGENTS.md`
2. `context/CURRENT_STATE.md`, when current state matters
3. `context/KNOWN_ISSUES.md`, when risks/errors/client data/automation are involved
4. `references/INDEX.md`, only when references are needed
5. Specific files selected by search or user instruction

Do not open all of `agents/`, `references/`, `context/`, or `skills/` by default.

## Local helpers

When searching, listing changed files, or summarising files, prefer `..\tools\codex-helpers\` before opening large files or scanning the project broadly.

## Operational memory

The `/context` folder is short operational memory. Update it only when there is a persistent project change.
