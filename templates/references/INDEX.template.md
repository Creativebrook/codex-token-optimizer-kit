# References Index

This file maps the `references/` folder.

Purpose: help Codex find the right context without opening unnecessary or long documents.

## Main rule

Read this `INDEX.md` before opening files in `references/`.

Use at most 1–3 reference files per task unless explicitly asked for deeper analysis.

Do not open every document by default.

## Structure

```text
references/
  INDEX.md
  project/
  library/
```

## Folders

### `project/`

Contains documents directly related to this project:
- brand;
- scope;
- strategy;
- client context;
- services;
- campaigns;
- reports;
- offers;
- operations.

### `library/`

Contains external references:
- guidelines;
- studies;
- legal/regulatory notes;
- frameworks;
- marketing research;
- platform documentation;
- market data.

Do not enumerate every file in `library/` if it changes often. Search by topic instead.
